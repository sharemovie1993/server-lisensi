🚀 JALUR LOKAL TERSEDIA Terhubung ke Wi-Fi Sekolah?

Server fisik sekolah saat ini AKTIF / MENYALA. Jika perangkat Anda terhubung ke jaringan Wi-Fi sekolah, Anda dapat langsung masuk melalui jalur server lokal tanpa internet publik.

📱 Pengguna HP di Wi-Fi Sekolah Masih Muncul Halaman Ini?
1. Tutup Penuh Browser: Tutup tab ini lalu buang/swipe close aplikasi Chrome atau Safari dari Recent Apps HP Anda, lalu buka kembali.
2. Matikan Fitur Private DNS: Di Android (Pengaturan → Koneksi / Jaringan → DNS Pribadi), pilih Mati atau Otomatis agar HP tidak mem-bypass router Wi-Fi sekolah.
🏫 Bagi Pengguna Sekolah (Guru / Siswa / Operator)
Agar aplikasi dapat diakses dari rumah atau luar sekolah, mohon hubungi Teknisi IT Sekolah untuk mengaktifkan modul koneksi online pusat.
🔧 Bagi Teknisi IT / Pengelola Server
Buka aplikasi Easy Tunnel Gateway Manager di server sekolah dan pastikan status koneksi adalah Connected menggunakan Kunci Lisensi sekolah Anda.
